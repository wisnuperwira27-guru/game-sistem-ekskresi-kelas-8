BIO-JELAJAH 3D

Misi Ekskresi (The Excretory Expedition)

1. Game Design Document (GDD)

Konsep: Pemain mengendalikan "Nano-X", kapal selam berukuran nano berteknologi tinggi di dalam tubuh manusia (Sudut pandang Third-Person).

Alur 4 Zona Level 3D:

  • Ginjal (Ngarai Nefron): 3D Tube Runner. Tangkap Air/Glukosa (Biru/Emas), Hindari/Tembak Urea (Hijau).
  • Hati (Pabrik Detoks): Puzzle Lab. Rombak sel darah merah mati dan amonia.
  • Paru-paru (Gua Alveolus): Zero-G Platforming. Tukar CO2 dengan Oksigen.
  • Kulit (Terowongan Pori): Manajemen Suhu. Buka katup keringat.

2. Naskah Voice Over (Cutscene Ginjal)

3. Rekomendasi Tech Stack

Versi Web (Prototipe ini): HTML5, WebGL (Three.js), CSS (Tailwind). Ringan dan jalan di browser tanpa install.

Versi Full PC/Mobile: Unity 3D (C#) atau Unreal Engine 5 (Blueprints). Cocok untuk material organik realistis (Subsurface Scattering) dan particle effects kompleks.
